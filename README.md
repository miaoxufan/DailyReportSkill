# Research Weekly Report Skill

一个用于整理科研实验记录并生成研究周报的 Codex skill。

## 功能

- 从实验日志、指标表、研究笔记和工作区记录中提取本周进展
- 区分正式验证结果、训练过程指标、可视化观察和计划任务
- 汇总已完成实验、失败原因、研究结论和下一步验收标准
- 支持输出 Markdown 周报或 Word 周报
- 强调数据集划分、评估协议、checkpoint 和指标来源的可追溯性

## 目录结构

```text
SKILL.md
agents/
  openai.yaml
references/
  report-template.md
```

## 使用方式

将本仓库作为 Codex skill 使用，并在任务中提出类似请求：

```text
根据工作区本周的实验记录生成研究周报。
```

生成正式 Word 周报时，建议同时使用文档处理 skill，以便完成排版、渲染和质量检查。

## 写作原则

- 不编造缺失的指标或实验结论
- 明确区分正式结果、临时结果、视觉观察和计划任务
- 保留失败实验和数据质量问题
- 为下一步实验写出明确的数据集、方法、预算和成功标准
- 用保守措辞描述因果关系和泛化能力
